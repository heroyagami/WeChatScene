# WeChatScene BGM 池

每日视频统一使用由用户提供的 `1.mp3` 与 `2.mp3` 合成的通用 BGM，后续不再每条临时挑音乐。

实际运行文件为：

```text
public/bgm/daily-01-02.mp3
```

合成顺序为 `1 → 2`，中间使用 1.2 秒交叉淡化，并统一响度。配置键继续使用 `forest-friends`，以兼容已有的每日输入。

## 最终选择

1. **Daily Mix 01 + 02** — 唯一默认主 BGM
   - 来源分段：用户提供的 `1.mp3` 与 `2.mp3`
   - 用途：全部每日法律咨询视频
   - 成片不足 106.82 秒时自动截取，超过时自动循环

2. **Heartwarming** — 情绪敏感题材
   - 来源分段：`04 - Arctic Rim - Heartwarming - 冰河.mp3`
   - 用途：未成年人、家庭矛盾、侵权受害等更需要克制情绪的内容
   - 原因：速度更慢，氛围更柔和

3. **Tarki's Home** — 科技/互联网题材
   - 来源分段：`10 - Galaxy Express - Tarkis Home - 太空.mp3`
   - 用途：AI、平台、网络侵权、互联网纠纷
   - 原因：有轻微科技感，但仍保持稳定底层节奏

具体选择规则见 `playlist.json`。

## 播放规则

- 同一条视频只使用 1 首 BGM。
- 视频比音乐长时循环播放到视频结束。
- 默认音量约 8%—9%，以“不干扰读微信文字”为准。
- 开头淡入约 0.8 秒，结尾淡出约 1.2 秒。
- 所有题材默认使用 `forest-friends`，实际指向 `daily-01-02.mp3`。

## 缺失保护

生产脚本会校验实际 MP3 是否存在。若配置了 BGM 但文件缺失，渲染直接失败并报告错误，不再静默生成无声视频。
